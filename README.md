A newspaper front page summing up Friday 13 November 2026 in one image: Europe joins the Ukraine peace talks, tankers hit in the Strait of Hormuz, Nvidia chief Jensen Huang resigns, a worldwide Microsoft 365 outage, the Brooklyn collapse, and more.

## Run it

```sh
python3 main.py
```

It copies the entry image from the repository to `$MAKEFUN_OUTPUT_DIR/entry.png` (else `/output/entry.png`). Python 3.13, standard library only, no network, deterministic.
